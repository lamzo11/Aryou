**1.1 Project Overview:**
The tool is designed to assist Aryou in optimizing daily operations at their car rental center.
It will provide real-time insights into workforce allocation, task management, and operational timelines, 
allowing Aryou to manage car flow efficiently and handle unexpected situations like last-minute absenteeism and unexpected car arrivals.

**1.2 Objectives:**
•	Optimize team creation based on available workforce and task requirements.
•	Estimate the time required to complete daily operations, considering both regular and unexpected tasks.
•	Provide dynamic adjustments in response to unexpected changes, such as unanticipated car arrivals or last-minute absenteeism.

**2. System Overview**
The tool will consist of a user-friendly interface that allows Aryou's management to input data, view real-time updates, and receive recommendations.
The system will analyze the input data to generate outputs that help streamline daily operations.
